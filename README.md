# 🧊 Cube Arena

큐브를 좋아하는 사람들을 위한 게임식 웹앱입니다. WCA 18종목 스크램블, 스택매트 타이머,
친구와 링크로 겨루는 프렌드 배틀, 손가락으로 노는 클락 미니게임까지 한 페이지에 담았습니다.
서버도 로그인도 없고, 모든 기록은 브라우저 `localStorage`에만 저장됩니다.

## 바로 쓰기

`index.html`을 열면 끝입니다. 빌드 도구가 필요 없습니다.
로컬 서버로 띄우려면 프로젝트 폴더에서

```bash
python3 -m http.server 8080
# http://localhost:8080
```

GitHub Pages에 올리는 경우 저장소의 **Settings → Pages → Deploy from a branch**에서
브랜치를 `main`, 폴더를 `/ (root)`로 두면 `https://<사용자>.github.io/<저장소>/`에서 바로 열립니다.
모든 경로가 상대 경로라 하위 디렉터리 배포에서도 그대로 동작합니다.

## 기능

### 사용 설명서
- 헤더 오른쪽의 **`?` 버튼**을 누르면 인앱 사용 설명서가 모바일 시트/데스크톱 모달로 열립니다.
  타이머·스플릿, FTO·클락, 친구 배틀 3단계, 미니게임, 홈 화면 설치, 데이터 안내를 한 화면에서 순서대로 읽을 수 있고,
  배경 탭·`✕`·`Esc`로 닫힙니다. 설명서가 열려 있는 동안 `Space`는 타이머로 전달되지 않습니다.

### 타이머
- **스택매트 방식**: 화면을 0.3초 이상 누르면 초록불, 떼면 시작. PC는 스페이스바 홀드.
- **15초 인스펙션**: 8초·12초 비프음과 색 경고, 15초 초과 `+2`, 17초 초과 `DNF` 자동 처리.
  인스펙션은 설정에서 끌 수 있습니다.
- **기록**: 종목별로 저장되고 `+2`·`DNF`·삭제를 목록에서 바로 고칩니다.
- **평균 4종**: **Ao5 / Ao12 / Ao50 / Ao100** — WCA 트림 규칙(양끝 1·1·3·5개 제거)으로 계산하고,
  중간에 DNF가 2개 이상 남으면 그 평균은 DNF가 됩니다. Best / Mean도 함께 표시합니다.
- **실력 티어**: 종목별 PB로 `Rookie → Challenger → Pro → Master → Grandmaster → World Class`
  등급이 정해지고, 다음 티어까지 남은 초(`-0.34s`)를 게이지로 보여 줍니다.
- **기록 추이 그래프**: 최근 50솔브의 싱글 라인 + 롤링 Ao5 라인 + PB 기준선 (SVG).
- **스플릿 측정**: 설정에서 켜면 솔브 중 화면을 탭할 때마다 **Cross / F2L / OLL / PLL** 구간이
  나뉘어 기록됩니다. 3번 탭하면 4구간이 나뉘고, 마지막 탭에서 멈춥니다.

### 종목 (18)
`FTO`(2027 신설) · `Clock`(~2027.07 레거시) · 3x3x3 · 2x2x2 · 4x4x4 · 5x5x5 · 6x6x6 · 7x7x7 ·
3x3 OH · 3x3 BLD · 3x3 FMC · 3x3 MBLD · Pyraminx · Skewb · Square-1 · Megaminx · 4x4 BLD · 5x5 BLD

- 각 종목은 직전 면이 겹치지 않게 뽑는 시드 기반 스크램블 생성기를 씁니다.
  (6x6·7x7은 `2R`/`3Rw` 표기, Megaminx는 7줄, Clock은 `y2` 앞뒤 10수, FMC는 `R' U' F` 프레임)
- **SVG 미리보기**: 3x3 · 2x2 · 4x4 · Pyraminx · Skewb · FTO · Clock.
  단순 그림이 아니라 실제 스티커 모델을 3D 기하로 돌려서 그립니다.
  FTO는 정팔면체 8면 전개도(면당 9개 삼각 스티커), Clock은 앞/뒷면 9개 시계바늘과 4개 핀 상태입니다.
- **Clock은 실제 기구 그대로**: 핀이 올라간 코너의 4개 다이얼(코너·양옆 에지·가운데)이 휠과
  함께 돌고, 핀이 여러 개면 그 그룹이 합쳐집니다. 코너 다이얼은 앞뒤가 같은 부품이라 항상 같은
  값을 가리키고, 핀이 내려간 휠을 돌리면 반대 면이 움직입니다. 스크램블도 WCA 형식
  (앞면 9수 → `y2` → 뒷면 5수)으로 생성합니다.

### 게임 요소
- 솔브마다 XP, 레벨업. **PB를 갱신하면 폭죽 + 효과음**이 터집니다. (효과음은 음소거 가능)
- **오늘의 퀘스트 3종**: 날짜 시드로 매일 새로 생성되고, 달성하면 XP를 받습니다. 연속 출석도 쌓입니다.
- **업적 17종**: FTO 개척자, 굿바이 클락, 첫 PB, Ao5 마스터, 배틀 승리, Sub-20 등.

### 프렌드 배틀 (서버 없음)
1. 종목·상대를 고르고 **배틀 링크 만들기** → 고정 시드가 담긴 링크가 만들어집니다. (카톡·디스코드 공유 문구도 한 번에 복사)
   상대는 **실제 친구(링크 공유)** 또는 **AI 라이벌(Challenger / Pro / Master / Grandmaster)** 중에서 고릅니다.
   친구 닉네임을 미리 적어 두면 배틀 카드 위 **VS 배지**와 리더보드에 그 이름이 바로 뜹니다.
2. 친구가 링크를 열면 **같은 5개 스크램블**로 바로 대결 모드에 들어갑니다.
   상대의 결과가 아직 없어도 리더보드는 `2  [상대이름]  대기 중...` 행을 보여 줍니다.
3. 친구의 **결과 링크**를 열면 친구의 5판 기록이 리더보드에 깔린 채로 **1라운드부터** 바로 도전합니다.
   내가 이미 그 시드의 배틀을 끝냈으면 결과 화면에 상대 기록이 더해집니다.
4. 승부는 **Ao5 트림 평균**으로 가립니다. 리더보드 아래에는 상대와의 **라운드별 차이**(`-0.24s` / `+0.18s`)가
   표시되고, **[결과 카드 저장]**으로 공유용 PNG 카드를 내려받을 수 있습니다. 배틀 도중에도
   **[🔗 초대 링크 복사]**로 친구를 바로 부를 수 있습니다.

### AI 라이벌 (고스트)
- 서버도 상대도 없이 바로 겨룰 수 있는 **시드 기반 고스트**입니다. 종목의 `TIER_TIMES` 기준 기록을
  봇의 평균적인 한 판으로 삼아 라운드마다 사람 같은 편차(±7~12%, 가끔 +2)를 줍니다.
  3x3 기준 Challenger ≈ 20초, Pro ≈ 14초, Master ≈ 10.5초, Grandmaster ≈ 8.5초.
- **같은 링크 = 같은 봇 기록**: 봇 기록도 배틀 시드에서 계산되므로, AI 라이벌로 만든 초대 링크를
  친구가 열면 똑같은 봇 기록과 겨룹니다. 기록은 링크를 아는 사람이면 누구나 볼 수 있습니다.

### 미니게임
- **클락 시뮬레이터 타임어택**: 핀 4개를 올리고 코너 휠을 돌려 18개 다이얼을 모두 12시로.
  첫 수에 타이머가 시작되고, 클리어 타임이 기록됩니다.
- **스크램블 챌린지**: 스크램블을 잠깐 보여준 뒤 사라지면, 순서대로 다시 입력합니다.
  노미스로 통과하면 레벨이 올라갑니다.
- **서든데스 릴레이**: WCA 18종목 전부 선택 가능. 종목마다 시작 목표가 다르고
  (2x2·피라밍크스·스큐브 8초 → 3x3·클락 15초 → OH 28초 → 4x4 55초 → 5x5 1:40 →
  6x6·7x7·BLD·FMC·MBLD 3:00~5:00) 라운드마다 줄어듭니다(3x3 15초 → 13초 → 11초 …).
  한 번이라도 넘기면 끝. 종목별 최고 생존 라운드가 기록됩니다.

## 파일 구성

```
index.html      화면 골격
styles.css      네온 다크 / 라이트 테마, 모바일 하단 탭바 ↔ 데스크톱 반응형
scrambles.js    종목 정의 + 시드 기반 스크램블 생성기
puzzles.js      3D 스티커 모델, 회전 생성, SVG 미리보기(큐브·정사면체·정팔면체·스큐브·클락)
app.js          타이머, 기록, 퀘스트·업적, 배틀, 미니게임
manifest.json   PWA 매니페스트
icon*.png/svg   앱 아이콘
```

## 데이터와 개인정보

- 기록·XP·설정·배틀 정보는 모두 그 브라우저의 `localStorage`(키 `cubeArena.v1`)에만 남습니다.
  서버로 보내는 값이 없고, 계정도 없습니다.
- 배틀 링크에는 **종목·시드·닉네임(직접 입력한 값)·AI 라이벌 티어** 만 담깁니다. 결과 링크에는 라운드 기록이 더해집니다.
  링크를 아는 사람은 그 기록을 볼 수 있으니, 공개하고 싶지 않은 닉네임은 쓰지 마세요.
- 설정 → **모든 기록 지우기**로 언제든 초기화할 수 있습니다.

## 단축키 / 팁

- `Space` : 타이머 홀드 & 시작·정지 (타이머·배틀 화면)
- `Esc` : 인스펙션·타이머 취소
- 모바일에서는 하단 탭바로 이동합니다. 홈 화면에 추가하면 앱처럼 열립니다.
